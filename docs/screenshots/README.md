# Interface previews

Screenshots of the interactive pages this repository serves from `docs/`, kept
so the README can show what the pages do without the reader opening them first.

| `argument.png` | `docs/argument.html`, "The integrated GSN argument, node by node" | <https://milinpatel07.github.io/Assurance-Gaps-in-an-Integrated-Safety-and-Cybersecurity-Case/argument.html> |

These are previews, not data. Each is a screenshot of the committed HTML loaded
in a browser at a fixed width. The pages themselves are generated and drift-checked
(see the repository README and `tests/`); these images are not, so they are
refreshed by hand when a page's appearance changes.
