# Interface previews

Screenshots of the interactive pages this repository serves from `docs/`, kept
so the README can show what the pages do without the reader opening them first.

| File | Page it shows | Live page |
|---|---|---|
| `interactive_argument.png` | `docs/gsn_view.html`, the tappable GSN argument | <https://milinpatel07.github.io/Assurance-Gaps-in-an-Integrated-Safety-and-Cybersecurity-Case/gsn_view.html> |
| `g5_playground.png` | `docs/g5_playground.html`, the four-scale acceptance tool at G5 | <https://milinpatel07.github.io/Assurance-Gaps-in-an-Integrated-Safety-and-Cybersecurity-Case/g5_playground.html> |

These are previews, not data. Each is a screenshot of the committed HTML loaded
in a browser at a fixed width. The pages themselves are generated and drift
checked (see the repository README and `tests/`); these images are not, so they
are refreshed by hand when a page's appearance changes.
