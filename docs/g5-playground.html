G5 playground: set acceptance lines for the four evidence types

In the WAISE paper's integrated GSN argument, G5 is the verification and validation (V&V) goal: it claims that the V&V evidence is sufficient. G5 is the one goal to which all four standards contribute, and each contributes one evidence type, (a) to (d) below, on its own measurement scale. No standard prescribes how the four combine into a single sufficiency claim; the paper records this as decision point DP-2.

Suppose every prescribed activity is complete. Set an acceptance line for each evidence type and read the result. The page applies one possible rule, that all four must pass; no standard prescribes it. In the case study only evidence type (c) was produced, on simulated outputs (AUROC 0.982 in the paper); the four values here are illustrative.

Whatever result you reach depends on four lines and a rule that you chose, on four scales with no common unit. The standards do not determine the sufficiency judgement at G5. The WAISE paper assigns the choice to the project: an evidence admissibility policy with documented rationale, following the precedent in ISO 26262 Parts 4 and 6 for replacing a recommended verification method, which the paper says can be extended to combining evidence across domains.
